# v0.2 设计文档：风险厌恶目标（库存风险项）

## 1. 动机

v0.1 验证暴露的明确短板：VWAP-opt 期望滑点 0.21bp 但日间波动 ±10.3bp，
oracle ±0.4bp 但期望 2.31bp——当前求解器是纯期望成本最小化（风险中性），
用户无法在"期望-风险"前沿上选点。经典解法是 Almgren–Chriss 式库存风险项。

## 2. 数学

### 2.1 目标泛函（求解器单位，T=1）

```
J(v) = η∫v² + ∫∫_{s<t} v(t)G(t−s)f(v(s))dsdt − ∫f(v)·q ds + λ∫₀¹(share − ∫₀ᵗv)²dt
```

λ = `ExecParams.risk`（默认 0）。风险项含义：持货期间的价格波动暴露，
库存 I(t) = share − ∫₀ᵗv。

### 2.2 梯度与 Hessian（推导要点）

```
∇R(u) = 2λ·∫_u¹ (1−s)v(s)ds − 2λ·share·(1−u)
H(u,s) = ∂²R/∂v(u)∂v(s) = 2λ·(1 − max(u,s))
```

Hessian 核 `2λ(1−max(s,t))` **对称、半正定、与 ε 无关**。

### 2.3 结构结论（本设计的关键）

风险项无 ε 依赖，因此：

1. **线性算子**：`A_new = A + K`，`K_ij = 2λ(1−max(t_i,t_j))·w_j`；
2. **基线右端**：增加常数向量 `r = 2λ·share·(1−t)`（与 VWAP cross-term 同构，
   但不进高阶源项）；
3. **扰动递推源项公式零改动**：各级 `A_new v_{m+1} − ℓ_{m+1} = −s_m` 的 s_m
   仍只由冲击项的级数合成。

即：cross-term 改变"逐阶源项"，risk-term 只改"算子与基线"——两者可叠加
（VWAP + 风险厌恶同时启用）。

### 2.4 离散化

直接按核构造保证对称（与连续 Hessian 一致），不通过 Ũ/L 分解组合：

```python
K = 2λ · (horizon − max(t_i,t_j)) · w_j      # 行作用于 v: (Kv)_i = Σ_j K_ij v_j
r = 2λ · share · (horizon − t)
```

`cost_operator(eta, risk)` 返回 `2ηI + P + Q + K`；`ConstrainedSolver` 一次
LU 分解同时服务基线与所有阶（计算量与 v0.1 相同规模，见 T8）。

### 2.5 量纲映射（真实数据模式）

实盘目标（价格单位）：`λ_real·σ_w²·X²∫(1−C_u)²dt`。除以冲击尺度 `XΛ` 归一到
求解器单位后：

```
risk_solver = λ_real · σ_w² · share / Λ        （realdata.solver_risk_scale 提供 σ_w²X/Λ）
```

`σ_w`（窗口波动）、`share`（X）、`Λ`（冲击尺度）均来自 `window_stats` 与
`calibrate`，前沿扫描取 `系数 × scale`，系数如 {0.05, 0.2, 1, 5}。

### 2.6 API 变更

| 位置 | 变更 |
|---|---|
| `ExecParams` | 新字段 `risk: float = 0.0`（求解器单位） |
| `Grid` | `horizon` 属性、`risk_operator(risk)`、`risk_vector(risk, share)`、`cost_operator(eta, risk=0)` |
| `ConstrainedSolver` | 构造参数 `risk=0.0` |
| `series.coefficients` | 新参数 `offset`（ε 无关常数右端，仅进基线） |
| `branch.*` | `risk` 参数贯通 `stationarity`/`hessian`/`continue_branch`/`reduced_hessian_min` |
| `ExecutionSchedule.expected_costs` | 新键 `risk_penalty = λ∫I²dt`（库存路径梯形积分） |
| `realdata` | `solver_risk_scale(stats, calib)` |

### 2.7 预期行为与有效域

- λ→0⁺：解收敛到 v0.1（rtol→0）；
- λ→∞：前载占比 →1（趋向开盘立即执行）——库存风险强迫尽快清仓；
- 中间 λ：库存暴露 ∫(1−C)²dt 单调下降（理论保证，实测亦然）；期望冲击成本
  单调不降；TWAP/naive 点被前沿**双维占优**（成本更高且库存暴露更大，
  不在有效前沿上）。

**有效域边界（实测确认）**：渐近级数要求线性基线为正（log(v) 递推）。对
VWAP 目标，基准返还项与强风险项都会把无约束线性基线的尾部推向负值——
profile 越尖锐、λ 越大，越容易越界（合成 U 型 sharpness=2 时 VWAP 族
λ≲0.1 安全，λ≥0.5 越界；真实 CU/BU 量型下 λ≤0.5 均安全）。越界时
`series.coefficients` 抛出带说明的 ValueError。**结构性解法是 v0.3 的
活跃集约束求解器**（在正锥上求解，long-only 钳制为其特例）。

**两口径风险的方向性差异（实测）**：λ 上升使执行前载、偏离市场量型——
IS 口径（对到达价）std 随 λ 单调**下降**（持货期缩短，漂移暴露减小）；
VWAP 口径（对市场基准）std 反而略**上升**（CU 10.3→11.6bp）——基准风险
是前载的诚实代价。风险预算应按口径分别设定。
