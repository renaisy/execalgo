# v0.4 设计文档：敏感性与稳健性扫描

## 方法

`execalgo/sensitivity.py`（存活表聚合，纯函数可单测）+ `scripts/sensitivity_scan.py`。
扫描轴：参与率 {1%, 5%, 10%} × 冲击强度 c_imp {0.5, 1, 2} × 核衰减 {×1.5, ×1.0, ×0.75}
× 品种 {CU, BU, MA, HC} = 108 格；测试期 2025 全年（243 天，H2 纯留出）。
风险维度由 v0.2 前沿单独覆盖，不进主网格。

## 存活判据（T13）

- naive − VWAP-opt > 0（VWAP 口径配对差）
- TWAP − IS-opt > 0（IS 口径）
- TWAP − VWAP-opt > 0
- 前载排序 0.5 < IS-opt < VWAP-opt

每格重解四策略并按各核自洽定价回放；判"稳健"阈值为同号率 ≥ 80%。
正基线越界的格标记 boundary 并从分母剔除（实测为零）。

## 结果

四项结论 108/108 格 100% 存活；最弱格 MA@1%×c0.5×快核（+0.10bp, t≈0.3），
与 v0.5 拟合核的边际缩减发现同向：小单、弱冲击、快衰减下塑形收益最小。
