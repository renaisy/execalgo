# v0.3 设计文档：日内滚动重规划

## 1. 结构

`execalgo/replanner.py` 的 `RollingPlanner`：每 K 分钟（默认 15）在剩余窗口
`[τ, T]` 上重解规范扰动问题，状态为（已成交量 → 剩余比例 φ、已建立的自体
冲击残余 I_past、当日量级信念 s_vol）。规划器全程无量纲：输入分钟成交量，
输出每分钟执行比例。`validate_real.py --rolling` 提供端到端回测。

## 2. 剩余窗口的正则变换（实现中确认的三个关键推导）

子窗口归一化到 [0,1]（长度 h = 剩余分钟/225），速率按 v = φu/h 变换
（u 为子正则速率，Σu=1），梯度逐项匹配得到：

| 项 | 正则形式 | 因子 |
|---|---|---|
| 滑移 | `η_j = η_solver·γ/h^{3/2}` | γ = √(φ·s_vol) |
| 瞬态冲击 | `∫∫u·G_h·√u`，G_h(σ)=G(σh) | 1（定义公共尺度） |
| 基准交叉 | `q_can = Q_h[p̃]`，**p̃ = p·h 未归一化**（质量 = 市场剩余份额 P_tail） | 1 |
| 冲击衔接 | `offset = I_unitfree/√(φh)` | 1 |
| 库存风险 | `risk_j = risk_solver·γ·√h` | 与 η 方向相反 |

两个实现期踩过的坑（已由 T9 判别测试锁定）：

1. η 因子初版漏了 h（写成 √φ/√h，正确是 √φ/h^{3/2}）——滑移项相对偏小；
2. **尾部密度被归一化**是最隐蔽的错误：子窗口交叉项必须用未归一化的
   p̃ = p·h。归一化会把 q 错放缩 1/P_tail（10–30%），破坏时间一致性。

## 3. 时间一致性（T9）

无新信息（当日量 = 训练平均、s_vol≡1）时，剩余问题与静态解的尾部精确
等价（最优性原理，目标可精确分解：past-past 常数、past-future = ∫v·I_past
线性项、future-future 不变）。数值上：

- **首段逐位一致**（首重解 = 同网格静态问题，atol 1e-10）——验证接线；
- 全天路径存在 L1≈0.1–0.3 的漂移——方向为目标**数值平坦方向**（前载方向
  成本曲率 ~1e-4），成本等价（相对差 ≤0.3%）；
- 去掉 I_past 衔接项则成本一致性被破坏（判别性消融）。

## 4. 修订阻尼（实现期发现，必要）

无阻尼的逐次重解在平坦方向游走，分钟级凸性（滑移 ηv²、分钟分块冲击）
把游走变成真实成本：CU 上滚动比静态差 −0.41bp（t=−0.9），且与子网格
分辨率无关（601/40 同样差，单发 301/20 与静态差 −0.0001bp 排除离散化）。
**修订阻尼**（新解与上一版计划按 α=0.5 混合）消除游走成本：

| 品种 | 静态−滚动（VWAP 口径） | 结论 |
|---|---|---|
| CU | −0.093bp（t=−0.3） | 平价 |
| BU | −0.038bp（t=−0.1） | 平价 |

这是开放环重求解的经典时间不一致现象的实证——模型平坦方向上的"自由"
漂移在任何真实凸性下都有代价，生产级重规划必须带阻尼或正则。

## 5. v1 滚动的诚实结论与后续

当前自适应通道仅量级（s_vol → 冲击尺度）：达成平价 + **IS 口径风险下降**
（CU 22.9→19.2bp、BU 38.6→36.5bp），但无显著期望增益；VWAP 口径 std
上升（偏离市场量型对齐，与 v0.2 风险前沿的口径分化一致）。原 T12 验收
（改善 t≥2）**未达成**，原因明确：量型信息只能经冲击尺度进入（归一化
交叉项天然与量级无关），而期望增益的主通道是**尾部形状预测**——即
v0.6 贝叶斯量型的任务。滚动机制本身（T9–T11）已验证正确，v0.6 接入
形状预测器即可激活增益。

活跃集约束求解器（v0.2 有效域的结构性解法）重定域到 v1.0 约束套件。
