# v1.0 设计文档：盘口感知执行 + 约束套件

## 约束求解（execalgo/constrained.py）

加边 KKT 系统上的活跃集箱约束 0 ≤ v ≤ cap：
- **线性精确解**：激活（原始违背）+ 释放（对偶最差违例）迭代至 KKT，
  残差 ~1e-15；不可行（w'cap < share）显式抛错。
- **延拓内嵌**（branch.py）：投影牛顿——步长解于自由集子矩阵；
  merit 函数取**自由集残差 + 等式行**（约束能行点全量残差不为零，
  活跃行由界乘子平衡）；裁剪后最小范数等式重投影；√ 导数在 0 处的
  固有奇异性以 1e-9 下限正则（仅冲击导数项）。
- 实现期三处关键修复：merit 口径、牛顿步符号约定（内部 −F 与调用方
  减步双重否定使步向反向）、非短路布尔表达式在 None 上限时崩溃。

## 盘口执行（execalgo/execution_model.py）

每分钟切片拆分：被动部分挂 bid，按对手方毛流量 × 队列捕获率 β 成交，
剩余吃单付半价差；开盘竞价分钟 taker-only；停牌分钟量顺延。
基准口径与 replay_day 一致（含自体冲击返还）。

## 数据层加固

分钟买/卖毛流量（mid rule 标记）；**退化盘口过滤**——跌停日 bid=0 快照
占 45% 会毒化 mid/价差（单日滑点虚增 ~1000bp），过滤为双边有效报价
（bid>0<ask，价差 ≤2%×mid）的中位数。

## 真实数据结果（CU 117 天，8%/min 上限）

上限在 11–13% 分钟绑定、前载 0.696→0.682；优化排序在两种执行模型下保持；
盘口模型把旧口径 ~1.9bp 线性滑移摩擦变为 ≈0（被动占比 49% 价差对冲）；
优化器在 VWAP 口径转为净负滑点（被动捕获 > 残余冲击）。
