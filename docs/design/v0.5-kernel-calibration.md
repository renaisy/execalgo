# v0.5 设计文档：真实数据核校准

## 识别链条（每一步都经合成受控模拟或 2 万天蒙特卡洛验证）

1. **符号响应**（`estimate_response`）：R(τ) = mean ε_t·(m_{t+τ} − m_{t−1})，
   成交前基准 m_{t−1}（成交后基准会把自身冲击衰减计入差分使响应为负）；
   符号加权（非成交量 OLS）——持续订单流下同向游程使成交量加权重尾，符号版稳健。
2. **双向混合结构**：R(τ)/E[q] = G(τ) + Σ_{l≤τ}C(l)G(τ−l) − Σ_{k≥1}C(k)[G(k−1)−G(k+τ)]。
   第二项（预交易冲击态的松弛/回撤）在持续流下使响应比核衰减更快——
   漏掉它偏差可达 ~70%（MC 验证）。
3. **双重闭合**：G(0) 由平滑外推 2G(1)−G(2)（对指数族精确）迭代；超出窗长的
   尾部 ΣC(k)G(k+τ) 由拟合参数族解析外推，温启动（用原始响应形状初始化）
   后前 80 滞后恢复误差 ≤0.0013（精确输入）/ ≤0.03（含噪声）。
4. **拟合**：对数参数化三指数族（保完全单调），只拟合 lags 1..L−10
   （尾部闭合最敏感的最后几滞后由族外推）。

## 实现期三个关键陷阱（均已锁定为测试）

- 响应基准必须取成交前；初始的成交后版本响应为负
- 松弛项的存在与符号（G0 记账在右端须一负一正）
- 拟合优化器须有参数界（trf），否则 log 参数溢出破坏尾部闭合迭代

## 真实数据发现

C(1)≈0.07（远低于股票 0.2–0.4）；拟合核持续性 ∫G(120min)≈97 vs 论文核 304；
T15 方向确认（快核 → 前载减弱）；拟合核自洽定价下优化边际约减半但方向保持。
